# SW-Radio engineering test record — 2026-10-23

Target sources: `project/sw-radio/` plus the existing branch's
`common/sys_sw_dfe_1mhz_nco14.v` (12-bit ADC, NCO14, MIX18, CIC20, FIR47).

Executed in Linux with Icarus Verilog 12.0 and Python 3.12:

Windows x86 ExtIO:

- Cross-compiled source to a **PE32 i386 DLL** using MinGW-W64 GCC 13.
- Confirmed exports include `InitHW`, `OpenHW`, `StartHW`, `SetCallback`,
  `SetHWLO`, `GetHWSR`, `ExtIoGetSrates`, with undecorated names.
- Statically linked MinGW C++ runtime; imports are Windows built-ins
  `KERNEL32.dll`, `msvcrt.dll`, `WS2_32.dll` only.
- The Visual Studio `.vcxproj` has **not** been compiled with MSVC.
- DLL loading and actual callback timing in HDSDR have **not** been tested.

Known limitations / mandatory next gates:

1. ADC and AD8370 pin LOCs are deliberately temporary and electrically
   **unsafe**; do not program the bitstream using them.
2. No Vivado installed in the test environment; **no verified synthesis,
   placement, routing, timing closure, or Artix-7 resource totals**.
3. Icarus emits a pre-existing `simple_ram.v` memory-range/readmemh warning;
   NCO test values and DFE end-to-end output are valid despite the warning.
4. No hardware ADC 12-bit ENOB/SNR, clock jitter, phase noise, alias rejection,
   true UDP packet loss, AD8370 analog gain, or HDSDR reception validated.
5. Follow-up integration should validate PHY RX IDELAY12 with actual eye/timing,
   RGMII TX PHY strap for internal delay, and XPM async FIFO testbench using
   the Xilinx supplied simulation library or Vivado xsim.
